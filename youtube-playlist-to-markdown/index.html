Install in one line

Claude Code

claude mcp add toolkb -- npx -y github:jack-reson8/toolkb-mcp

Codex (~/.codex/config.toml)

[mcp_servers.toolkb]
command = "npx"
args = ["-y", "github:jack-reson8/toolkb-mcp"]

Cursor, Claude Desktop, Windsurf (mcp.json)

{ "mcpServers": { "toolkb": { "command": "npx", "args": ["-y", "github:jack-reson8/toolkb-mcp"] } } }

Needs Node.js 18+. Runs locally, no API key, no account. Behind a proxy? HTTPS_PROXY is picked up automatically.

FAQ

How many videos can it read?

It lists up to 500 videos and pages through long playlists automatically. With transcripts on, it includes as many transcripts as fit in about 90,000 characters (Claude Code's tool output limit) and tells your assistant which videos to fetch one by one.

Does it work with channels?

Yes – pass a channel URL like youtube.com/@handle or /channel/UC… and it reads the channel's uploads.

What if a video has no captions?

It is listed as skipped; videos are never downloaded.

Is there a terminal version?

Yes: npx -y -p github:jack-reson8/toolkb-mcp toolkb playlist <url> --transcripts 10 writes the full document with no size cap.
