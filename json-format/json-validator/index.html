在线 JSON 校验

粘贴 JSON，如果有语法错误会提示出错信息，没有错误则美化输出。



Pro 批量版即将上线：点此候补登记


怎么用
  1. 把内容粘贴到上面的输入框，或点“载入示例”。
  2. 点“计算 / 转换”。
  3. 点“复制结果”带走即可。
输入格式：粘贴 JSON，美化、压缩或指出语法错误。以 ! 开头表示压缩。


常见问题
在线 JSON 校验适合谁用？
主要面向开发者，但任何需要同样计算的人都可以使用。
数据会上传到服务器吗？
不会。JSON 格式化与校验的所有计算都在你的浏览器里完成，输入的内容不会被发送或保存。
免费版有什么限制？
免费版每次最多处理 20 行输入，足够日常使用；需要批量处理时可以升级 Pro。
结果准确吗？
结果按公开通用的公式计算，仅供参考；涉及合同、税务、医疗、学籍等正式用途，请以官方或专业人士意见为准。
