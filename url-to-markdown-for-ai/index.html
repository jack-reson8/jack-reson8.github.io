Install in one line

claude mcp add toolkb -- npx -y github:jack-reson8/toolkb-mcp

Codex (~/.codex/config.toml)

[mcp_servers.toolkb]
command = "npx"
args = ["-y", "github:jack-reson8/toolkb-mcp"]

Cursor, Claude Desktop, Windsurf (mcp.json)

{ "mcpServers": { "toolkb": { "command": "npx", "args": ["-y", "github:jack-reson8/toolkb-mcp"] } } }

FAQ

Why not just let the assistant fetch the page?

Built-in fetchers often return raw HTML or truncated text. toolkb isolates the article body, keeps headings, lists, code blocks and links, and makes every link absolute.

Does it handle documentation sites?

Yes. When the article extractor finds too little text it falls back to the page's main content area, which suits docs and knowledge bases.

Can it read PDFs?

Not yet – PDF links are on the roadmap.

Is there a length limit?

Output is capped at 60,000 characters by default; set max_chars to change it.
