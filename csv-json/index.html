CSV ⇄ JSON 转换器

粘贴 CSV 或 JSON，立即互相转换，全部在浏览器本地完成。



升级 Pro：批量处理，解除 20 行限制（HK$39 / 30 天）


怎么用
  1. 把内容粘贴到上面的输入框，或点“载入示例”。
  2. 点“计算 / 转换”。
  3. 点“复制结果”带走即可。
输入格式：粘贴 CSV 或 JSON，立即互相转换，全部在浏览器本地完成。


常见问题
数据会上传到服务器吗？
不会。CSV ⇄ JSON 转换器的所有计算都在你的浏览器里完成，输入的内容不会被发送或保存。
免费版有什么限制？
免费版每次最多处理 20 行输入，足够日常使用；需要批量处理时可以升级 Pro。
结果准确吗？
结果按公开通用的公式计算，仅供参考；涉及合同、税务、医疗、学籍等正式用途，请以官方或专业人士意见为准。
